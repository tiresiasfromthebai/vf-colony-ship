# VF de Colony Ship

Traduction française non officielle de [Colony Ship: A Post-Earth Role Playing Game](https://store.steampowered.com/app/648410/) (Iron Tower Studio).

La version 1.0 couvre **le jeu entier** : plus de 22 000 textes, de la Fosse jusqu'aux écrans de fin. Elle comprend les dialogues, les quêtes, le journal, les objets, l'interface et l'écran du choix de difficulté. Les répliques s'accordent au genre de votre personnage. C'est une première version : vos retours sont les bienvenus.

## Téléchargement

Dans l'onglet [Releases](../../releases), l'archive `VF_Colony_Ship_<version>.zip` (1,6 Mo) contient un seul fichier de jeu et un LISEZMOI. Elle ne contient aucun script ni exécutable. La même archive est publiée sur Nexus Mods.

## Installation

1. Fermez le jeu.
2. Extrayez l'archive dans le dossier du jeu (Steam : clic droit sur le jeu, Gérer, Parcourir les fichiers locaux). Le fichier `pakchunk99-WindowsNoEditor_P.pak` doit arriver dans `ColonyShipGame/Content/Paks/`.
3. Lancez le jeu, puis choisissez Options > Langue > « Français - Community Translation ».

Pour désinstaller, supprimez ce fichier.

## À savoir

- Vos **sauvegardes ne sont pas touchées** : une partie en cours se poursuit en français.
- Après une mise à jour du jeu, la VF continue de fonctionner. Seuls les textes modifiés par la mise à jour repassent en anglais, en attendant une nouvelle version.
- Les boutons du choix de difficulté (HÉROS, OUTSIDER, PERSO) sont des images. Ils restent en français même si vous repassez le jeu en anglais.

## Choix de traduction

- Le narrateur vous **vouvoie**. Chaque personnage tutoie ou vouvoie selon son caractère.
- Le jeu est sec, cynique, souvent drôle : la traduction cherche l'effet plutôt que le mot à mot.
- Les factions et les lieux sont traduits (la Fraternité, l'Alliance, les Protecteurs, l'Église, la Fosse…). Les noms des personnages restent tels quels.
- Les citations bibliques suivent la Bible Segond.

## Transparence sur l'IA

Cette traduction est faite **avec l'aide d'une IA** (Claude, d'Anthropic), sous la direction d'un joueur francophone qui a fini le jeu. Elle s'appuie sur :

- une charte de style et un lexique ;
- une relecture indépendante de chaque partie du jeu, comparée à l'anglais ;
- une harmonisation globale ;
- des tests en jeu.

Le résultat n'est pas parfait : vos retours comptent.
